# Olevod Android TV App

面向个人使用的 Google Chromecast with Google TV 原生客户端，深色/绿色TV界面，支持遥控器操作。

当前可安装测试版：真实首页与分类浏览、搜索、点播/VIP、播放控制、电视登录、本机历史与云历史同步、影视收藏、直播与节目回看。已通过Android TV模拟器和独立agent验证；频道收藏取消及Chromecast实机验收情况见进度表。
