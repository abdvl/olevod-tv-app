# 欧乐 TV · Olevod Android TV

为 Android TV / Google TV 制作的个人使用客户端，使用 Kotlin、Jetpack Compose 和 Media3 原生播放器。界面以深色和绿色焦点为主，围绕电视遥控器设计，接入 [欧乐影院](https://www.olevod.com/) 的影片目录、搜索和账号功能。

这是个人项目，与欧乐影院官方没有隶属关系。影片、海报、分类与播放源来自网站；官方标识的素材来源见 [品牌资产说明](docs/BRAND_ASSETS.md)。

## v0.2 界面与功能

**拿起遥控器，找到下一部想看的。**

打开就能继续上次的观看，也可以从电影、电视剧、综艺、动漫和 VIP 榜单里慢慢挑一部。完整海报、清晰文字和绿色焦点，让大屏上的每一步都更顺手。

[全部新版界面截图](docs/screenshots/v0.2/README.md)

![欧乐 TV 首页：继续观看与精选推荐](docs/screenshots/v0.2/home.png)

### 上次看到哪里，打开就知道

最近看过的影片就在首页第一行，海报上直接显示集数和观看时间。移动到一部影片，就能看到更完整的信息，按下确认继续看；想找更早的记录，进入末尾的“全部历史”即可。

下面是大幅精选推荐，以及电影、电视剧、综艺、VIP 和短剧的最近更新。顶部一行导航连接搜索、各个分类、目录、历史、收藏和账号，常用入口都在手边。

### 今天看什么，从榜单里挑

每个分类都有自己的小首页，先看人气，再看评分。前两部用大卡片突出展示，海报的颜色柔和地铺进背景；下方再展示最多十部影片，每排五张。完整竖版海报配上右上角评分，选片时一眼就能比较。

普通分类聚焦今年的影片；VIP 从全部年份的片库中挑选。还想多逛逛？底部“浏览全部”可以直接进入对应目录。

![电影榜单：Top 2 海报背景与完整竖版海报](docs/screenshots/v0.2/category-movie.png)

![VIP 榜单：从历年片库里找值得重看的电影](docs/screenshots/v0.2/category-vip.png)

### 想看哪一类，几下就筛出来

按类型、地区、年份缩小范围，再选择最近更新、最新上传、人气或评分排序。筛选选项需要时才展开，片库页面保持清爽。

向下浏览会自动接着加载，选片不用来回翻页。看完影片返回，也能接着刚才的位置逛。

![影片目录：清晰的筛选入口和完整海报](docs/screenshots/v0.2/catalog.png)

![筛选浮层：选好条件，再应用到片库](docs/screenshots/v0.2/catalog-filter.png)

### 少输入几个字，也能找到

用遥控器输入字母或数字，中间的“猜你想搜”会给出联想片名。例如输入 `MN`，可以从建议中选择“魔女”，不用逐个输入汉字。也可以切换系统输入法输入中文。

确认片名后，焦点会来到右侧第一部结果。按返回先回到输入框，换个关键词继续找。

![搜索联想：输入首字母，选择想找的片名](docs/screenshots/v0.2/search-suggestions.png)

![搜索结果：选中建议后，直接开始挑片](docs/screenshots/v0.2/search-results.png)

### 看得投入，操作顺手

全屏、暂停、前后跳 30 秒或 5 分钟、0.5×–2× 倍速、收藏，都放在视频下方。剧情简介保持简短，想细看时再展开。

长剧按十集分组，不必沿着一长串集数慢慢移动。选好一组，再确认要播放的那一集；下一集也可以自动接着播。

![播放页：影片介绍、常用控制与十集分组](docs/screenshots/v0.2/player.png)

进入全屏后，控制栏半透明地浮在视频上，出现或隐藏都不会挤动画面。在主控制区按上键收起控制栏，按下键唤回；片源提供时，右侧还能看到当前分辨率和码率。

![全屏播放：控制栏覆盖画面，选集仍然触手可及](docs/screenshots/v0.2/fullscreen.png)

### 追过的剧、想看的片，都留得住

观看历史显示海报、影片信息、集数和进度，选中即可续播。本机记录支持删除和清空；登录后，还能查看网站历史与收藏，把想看的影片先收起来。

![观看历史：找到影片，也找到上次的进度](docs/screenshots/v0.2/history.png)

账号密码会加密保存在当前设备。需要重新登录时会自动填好，只需输入新的图片验证码。账号页提供数字键盘，也能随时更换账号或清除记住的信息。

![账号页：电视直接登录，减少重复输入](docs/screenshots/v0.2/account.png)

### 遥控器就够了

用方向键移动绿色焦点，按确认键打开影片或执行操作；按返回逐级回到上一步。详细按键路径见下方的[遥控器操作速查](#遥控器操作速查)。

误按返回也不用担心：退出前会先询问，默认停在“继续观看”。

![退出确认：误按返回时，可以继续观看](docs/screenshots/v0.2/exit.png)

## 遥控器操作速查

| 所在位置 | 操作 | 结果 |
| --- | --- | --- |
| 通用 | 方向键 / 确认键 | 移动绿色焦点 / 打开或执行选中项 |
| 首页最近播放 | 上 | 回到单行导航“首页” |
| 单行导航“首页” | 下 | 进入最近播放；没有记录时进入推荐 |
| 分类或目录 | 左右 / 上下 | 切换当前区域的选项或影片；按确认打开筛选浮层 |
| 搜索联想词 | 确认 | 搜索该词，加载后聚焦第一条结果 |
| 搜索页面 | 返回 | 先聚焦输入框，再按一次退出搜索 |
| 非全屏播放控制 | 上 | 聚焦视频画面 |
| 非全屏视频画面 | 确认 / 下 | 进入全屏 / 回到控制按钮 |
| 播放主控制区 | 下 | 进入选集分组 |
| 选集分组 | 下 / 上 | 进入当前组集数 / 回到控制按钮 |
| 具体集数 | 上 / 确认 | 回到分组 / 播放选中集数 |
| 全屏主控制区 | 上 | 隐藏控制栏 |
| 全屏隐藏控制栏时 | 下 / 左右 | 唤醒控制栏 / 后退或前进 30 秒 |
| 全屏播放 | 返回 | 退出全屏，保留当前播放 |
| 非全屏播放 | 返回 | 返回来源页面 |
| 首页 | 返回 | 打开退出确认 |

控制按钮或分组超出当前可见宽度时，可以继续向右移动。焦点高亮表示当前遥控器操作目标，描边或较暗的绿色也可能表示已选分类或正在播放的集数。

## 安装与升级

1. 从 [v0.2 Release](https://github.com/abdvl/olevod-tv-app/releases/tag/v0.2) 下载 `olevod-tv-v0.2.apk`，可用同页的 `SHA256SUMS.txt` 校验文件。
2. 将 APK 传到电视，用文件管理器打开；按系统提示允许该文件管理器安装未知应用。也可使用电脑通过 ADB 安装。
3. 安装后在电视应用列表中打开“欧乐 TV”。需要会员内容或网站历史/收藏时，在账号页登录。

**已经安装 v0.1 正式版，可直接覆盖更新，无需卸载。** v0.2沿用原发布证书，覆盖升级会保留本机数据；登录会话是否仍有效取决于网站。

**已经安装 Android Studio / ADB 开发调试版的用户请先阅读迁移说明。** 正式版使用独立发布证书，与此前 debug 版签名不同，同包名无法直接覆盖安装。卸载开发版会删除本机历史、搜索记录、登录状态和记住的账号密码；网站已有的云历史和收藏不受影响。应用目前没有本机数据导出功能，应先确认需要保留的记录已同步。

后续同一发布签名的更高版本可以覆盖升级。文件管理器安装、无线 ADB 配对、签名冲突及迁移步骤见 **[完整安装教程](docs/INSTALL.md)**。

## 当前验证范围与限制

- **正式 APK 与实机验证分别记录。** v0.1 发布包在干净模拟器上验证安装，v0.2 原签名包已在专用模拟器验证覆盖升级和搜索网络错误恢复；具体安装包与范围见[最终报告](docs/verification/RELEASE_V0_2_FINAL.md)。同功能 debug 版已在 Google Chromecast with Google TV（sabrina，Android 14）上验证普通点播、VIP 与遥控器操作，用户确认实际音画正常。尚未声称正式发布包完成 Chromecast 实机安装验收。
- **直播与回看仍属实验功能。** v0.2界面暂不提供这些入口，已有实验能力仍保留在代码中；部分频道会发生来源错误或不稳定，进一步稳定性排查暂缓。频道取消收藏也存在服务端返回成功但列表未确认更新的情况，不能与已验证的影视收藏等同。
- **VIP 需要网站有效会员。** “VIP 蓝光”是网站分类名称，不代表每个片源都是 4K/HDR。实际清晰度、音轨与播放能力取决于片源、会员权限、网络和设备解码支持；4K/HDR 尚未验收。UI v2 指定开发包的30分钟普通播放采样见下方实机报告，不等同所有片源或最终签名发布 APK 的长时验收。
- **云同步不是离线备份队列。** 网络失败时保留本机进度；尚无持久化离线补传队列，系统终止进程时不保证最后一次网络同步完成。网站历史数量受网站保留策略影响，暂不支持云端删除或批量迁移；本机删除只影响本机记录。
- **登录依赖当前验证码。** 识别错误或验证码过期时需要刷新重试。记住的凭据只保存在当前设备，清除应用数据或卸载会删除它们。
- **网站接口可能变化。** 本项目通过网站现有接口获取内容，影片下架、接口调整、网络故障及播放源异常会影响可用性。
- **面向电视。** 最低 Android 8.0，要求 Android TV / Google TV 环境；未提供手机触控布局或 Play 商店分发。

## 开发与测试

技术栈：Kotlin 2.1.20、Jetpack Compose for TV、Media3、AGP 8.9.2、Gradle 8.11.1、JDK 17、compile/target SDK 35。

使用 Android Studio 打开仓库根目录，配置 JDK 17 和 Android SDK 35 后同步。已配置本仓库本地工具链时，也可运行：

```sh
source scripts/android-env.sh
./gradlew assembleDebug testDebugUnitTest lintDebug
```

当前 47 项 JVM 单元测试覆盖 API 参数及解析、累计加载、迟到响应、播放跳转／续播、Unicode 输入和视频信息格式。新版 Android 测试另外覆盖遥控焦点、搜索竞态、分组／全屏、历史删除／来源恢复、收藏和账号隔离；精确运行范围及结果见 [V2-10](docs/verification/v2/V2-10.md)、[最终签名包验证](docs/verification/RELEASE_V0_2_FINAL.md)和[搜索错误恢复回归](docs/verification/v2/SEARCH_RETRY.md)。真实登录、会员内容、收藏及云同步集成测试需要额外账号环境和显式参数，不能将跳过的测试视为通过。
