# 云历史能力检查点

当前实现提供按账号/访客隔离的本机完整点播历史，按影片合并最新观看位置，不限制18条。它不是云历史的镜像，也不是每次播放事件的审计日志。

## 已确认

- 网站 `tv-pc-back.1787324346000.js` 实际读取浏览器本地记录并显示；进入历史页会调用 `/pub/user/watches/sync`。
- 网站同步字段 `duration` 来自当前播放秒数，`percent` 却来自总时长，不能因为字段名就发送百分比。
- 网站API声明了 `/pub/vod/history/list`，当前历史页代码没有使用它。
- 本轮匿名POST：history/list 与 watches/sync 都返回业务code12，要求登录。

## 仍待账号验证

- 登录后的云历史列表返回形状、总数/分页、与网页本地记录的关系。
- 服务端同步去重、时间戳与冲突规则，是否能拉取全部旧历史。
- 在未拿到真实响应前，App没有自动上传、合并或覆盖云历史；避免把未验证字段误写入账号。

## 恢复下一步

1. Mac解锁后可继续检查已登录Chrome会话；电视新登录需要新鲜图片验证码。
2. 先只读验证云列表，再用新建的测试观看记录验证同步；不得改写账户已有历史来试错。
3. 根据结果实现可用的同步范围，或明确保留本机历史、网站无法拉取的限制。
