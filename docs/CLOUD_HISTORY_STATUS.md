# 云历史能力与验证

本机历史按账号/访客隔离，按影片保存最近集数和位置，不限制18条。网站历史独立分页读取，每页20条；不会用本机旧记录覆盖整个账号历史。

## 已实际确认

- Android验证码登录及跨进程加密会话通过；账号历史 `POST /pub/vod/history/list` 返回 list/page/pageSize/total。
- 列表 `vodId` 是影片ID；`watchDuration` 是观看秒数，`watchPercent` 是总时长秒数。
- 用户明确授权新观看记录同步。`POST /pub/user/watches/sync` 使用网站数组字段：id/title/episode/duration/percent/saveTime/type，时间和时长均为整数秒。
- 真实VIP影片观看记录同步后，网站回读117秒进度、1050秒总时长、对应集数；测试通过。首次小数秒请求出现列表延迟且进度为0，已改用网站整数格式，并等待回读，不能仅以code0判定成功。

## 实现范围

- 本地与云端分别按产生顺序处理；本地保存不等待网络，避免旧进度反向覆盖和慢网阻塞。
- 正常播放30秒节流；暂停、切集、后台、退出触发最新记录同步。冻结发起时账号，切换账号后丢弃旧账号待发送云任务。
- 网络错误保留本机进度并提示；下次观看重试。后台进程被系统杀死时不保证最后一次网络请求完成，当前没有持久化离线补传队列。
- 云列表可分页显示服务端提供的全部记录；不保证网站自身保留所有历史。点击云记录按其集数和位置续播。
- 本机删除只影响本机，未实现云端删除或批量历史迁移。
