# 历史丰富卡片实现检查点

本机与网站历史统一采用可聚焦的影片卡片：封面、片名、存在的年份/地区/评分、更新备注、集数、观看时间/总时长与进度条。本机另保留独立删除按钮。没有总时长时不显示伪造总长或进度条，缺少元数据时不编造默认值。

云历史契约中可用vodId/episode/watchDuration/watchPercent，后两者已由API转为毫秒；本机WatchRecord保存完整MovieJson及毫秒位置。仅缺少封面/年份/地区/评分的可见行请求现有detail补齐，同页缓存、最多3个并发；请求使用入页固定token，账号变化重建loader。详情失败保留现有记录，继续播放不依赖补全成功。

两种历史点击均明确设置pendingResume，补全元数据时保留原集数与进度，不改写原观看记录或上传额外数据。

验证：assembleDebug与lintDebug成功（6秒）。实机视觉与焦点截图待随集成版本补验；本检查点不宣称已实机验收。
