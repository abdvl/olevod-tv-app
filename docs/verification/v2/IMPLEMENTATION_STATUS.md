## 恢复执行

1. 先查 `git status`、最新提交和 [PROGRESS](../../PROGRESS.md)，保留尚未提交的进行中工作。
2. 使用 `source scripts/android-env.sh`；本机 adb 端口需允许运行在普通桌面环境。
3. 只跑当前阶段对应测试，独立验证记录保留失败轮次与修正结果。
4. 模拟器结果与 Chromecast 实际音画、遥控器、性能验收分开记录。
5. 用户后续已授权推送和发布v0.2；沿用原release签名，不覆盖v0.1附件。先核对最新发布验证与PROGRESS，避免重复打包或宣称尚未完成的上传。
