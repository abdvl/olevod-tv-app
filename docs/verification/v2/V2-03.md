## 测试夹具与隔离

独立新增 [V2HomeUiTest.kt](../../../app/src/androidTest/java/com/olevod/tv/V2HomeUiTest.kt)。夹具包含八条本地观看记录、两条推荐，图片地址为空，首页使用 `fixtureRecords` 显示其中最近五条。直接使用生产 `ConnectedHome`，没有复制一份测试专用首页。

`FixtureApplication` 为 SharedPreferences 和 SQLite 路径添加每个测试独有的前缀；AppViewModel 构造时的账号和历史读取均落在新的空存储。没有调用 loadHome、登录、record 或网络元数据补全。结束后关闭 ViewModel/数据库，只删除本测试命名空间的存储。真实登录及观看数据不进入断言或截图。

实际组合还包含 `ContentFocusScope`、`SaveableStateHolder`、`PageFocusController` 和 `EdgeBringIntoViewSpec`。播放器与历史目的页是可返回的占位目标，用于证明首页的回调和来源恢复；它们不是实际播放或完整历史页面的替代验收。

除初次建立入口焦点外，流程均由 D-pad、确定和返回按键执行；未用 performClick 或直接请求焦点跳过被测导航路径。宽度动画等待由 Compose 测试时钟处理。

## 构建与首轮失败记录

构建阶段发现两项问题，均保留日志：

1. 首次生产编译在 `ConnectedBrowse.kt:117–122` 失败：`Function0<Int>` 不能传给 `Function0<Unit>`。主执行 agent 将 close 回调显式声明为 `() -> Unit` 后解除。此为构建验证，不是目录 UI 验收。
2. 新测试读取 `DpRect.width` 的写法不适用本项目当前 Compose 版本；独立验证 agent 改为 `right - left`。随后 app/test 构建成功。该修正没有改变边界断言的意图。

首轮三个测试均在初始入口失败，尚未执行其导航和布局断言：

```text
java.lang.IllegalStateException: FocusRequester is not initialized.
at com.olevod.tv.V2HomeUiTest$showFixtureHome$1$2$1.invokeSuspend(V2HomeUiTest.kt:214)
Tests run: 3, Failures: 3
```

`UnifiedHeader` 此时已使用 BoxWithConstraints 子组合，夹具外层的 `LaunchedEffect(Unit)` 立即请求 Home，早于其 focus target 挂载。夹具改为等待一帧后建立初次入口，再执行原有三条路径，全部通过。没有放宽布局或导航断言。

同样的立即请求写法也存在于冻结版本的 `OlevodApp.kt`。此风险已通知主执行 agent。报告编写时只读确认当前工作区 `OlevodApp.kt:98` 也加入 `withFrameNanos {}`；但本轮没有安装该修改后的 App 并验证真实 MainActivity 冷启动，因此该项只有源码修正确认，尚无本轮真入口运行结论。

曾尝试用 `-x :app:compileDebugKotlin` 只打测试包，但 Kotlin friendPaths 任务依赖拒绝，未生成产物。随后正常运行 assembleDebugAndroidTest 成功，始终保留原冻结 App 不变。
