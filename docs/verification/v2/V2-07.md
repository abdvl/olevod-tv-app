## 测试设计与结果

新增 [V2PlayerUiTest.kt](../../../app/src/androidTest/java/com/olevod/tv/V2PlayerUiTest.kt)。夹具使用真实 UnifiedHeader/PageFocusController，32 条连续索引的空 URI 剧集，长简介文本，以及纯色虚拟视频。动作记录传给播放器的参数并更新 PlayerUiState，不使用 AppViewModel、媒体解码器或网络。

初始焦点由生产 PlayerContent 建立在全屏按钮；后续路径全部使用遥控器方向、确定、返回和媒体键，没有点击或直接请求某个待测目标焦点。

| 用例 | 结果 | 已证明范围 |
| --- | --- | --- |
| `eightControlsStayVisibleAndHeaderDownReturnsToVideo` | 通过 | 默认全屏按钮聚焦；八按钮标签/语义、左右顺序、未裁剪边界和互不重叠；长简介存在时首组及首集仍可见；播放/收藏各调用一次，四个 seek 分别传入 −30000/+30000/−300000/+300000；末按钮上到视频，再上 Header Home、下回视频，确定全屏，Back 返回普通模式。 |
| `fullscreenUpDownKeepsVideoGeometryAndHiddenSeekDoesNotShowControls` | 通过 | 全屏显示注入的 1920×1080 和 4.20 Mbps；连续三轮 Up 隐藏、Down 显示并聚焦全屏按钮；视频外框和虚拟视频的四条未裁剪边界始终在 0.5dp 内一致；隐藏时左右传入 ±30 秒且不显示控制栏；再次显示八按钮和分组仍可见。 |
| `episodeGroupsOnlyPreviewUntilConfirmedAndSpeedRestoresItsTrigger` | 通过 | 分组方向移动不改可见组；确认 21–30 后显示十个实际条目且未播放；确认22才切集；集上回组、组上回控制；速度预览0.75不提交，Back回速度，确认1.5后回速度；切全屏保留选组/速度，末组只显示31/32，右边界不虚构33，确认32才切集；集/组上键不错误隐藏，控制上键才隐藏。 |
| `unseekableControlsRemainVisibleButRemoteSkipsAndIgnoresThem` | 通过 | 不支持 seek 时四个跳转按钮仍可见但disabled；方向从播放直接到速度、反向同样跳过；媒体快进/快退不触发 seek。 |

几何用 `getUnclippedBoundsInRoot()` 比较，避免祖先裁剪掩盖实际溢出。全屏用例使用暂停状态，避免将自动隐藏计时与手动 Up/Down 混为一个结论。

## 未由本轮证明的范围

- ExoPlayer seek 的实际位置、音画同步、片头片尾 clamp、实际视频分辨率/码率来源、HDR/音轨和设备解码。当前分辨率/码率只证明注入值可显示；seek 回调只证明 UI 参数准确。
- 真实 NativePlayer 离开路由保存/释放、进入后台保存/暂停、自动下一集、错误/重试、会话之间的速度默认值。
- 5 秒自动隐藏、缓冲/暂停/错误对计时的阻止、TalkBack 与大字体。
- 100/1000 集及非连续 episode.index、节目特别篇长标题、元数据变化时的分组焦点恢复。
- 实际根路由的 Header 切页和返回。测试中的返回动作控制虚拟全屏状态，不声称验证真实 App 路由栈。
- 简介展开浮层的长文滚动和返回焦点。本轮只验证长简介不会挤掉控制/首集。
