# 欧乐 TV v0.3 · 设置与应用更新

头像左侧新增齿轮入口，可在电视上检查 GitHub 最新正式版本，为后续播放器设置预留扩展结构。

## 新增功能

- 设置页首期提供“检查新版本”，支持遥控器操作。
- 发现新版后展示版本、大小与更新说明；点击“下载并安装”显示下载进度。
- 安装前校验 APK 大小、SHA-256（发布提供时）、包名、签名及内部版本，避免错误附件覆盖安装。
- 首次安装引导开启系统安装权限，由用户在 Android 安装器中确认；网络错误、限流或取消安装后可重试。

## 下载与升级

在 Assets 下载 **olevod-tv-v0.3.apk**，使用 **SHA256SUMS.txt** 校验。应用版本 **0.3.0 / versionCode 3**，支持 Android TV / Google TV，Android 8.0 及以上。

**v0.1 / v0.2 正式版需要手动下载本次 APK 并覆盖安装**，无需卸载。v0.3 起提供应用内更新入口，后续版本可从设置页检查。开发调试版签名不同，不能直接覆盖正式版。

SHA-256：`419002360d85457f6c7572e26130b414134a5ded0ef5f5e5e8d087dce473aae8`

## 验证范围

Release 构建、52 个单元测试、lint 与签名校验通过；2 个模拟器导航测试通过。正式包已在 Android TV 模拟器从 v0.2 覆盖升级至 v0.3，首次安装时间保留，设置页可运行并检查更新。

本次未进行物理电视验收，也未验证未来新版经应用内下载、授权、系统安装的完整往返；进程被系统终止后需重新检查下载。
