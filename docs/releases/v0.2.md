# 欧乐 TV v0.2

全新原生电视界面。应用版本0.2.0（versionCode2），最低Android8.0，包名`com.olevod.tv`。

## 下载与升级

下载 Assets 中的 **olevod-tv-v0.2.apk**，同页 `SHA256SUMS.txt` 可检查文件完整性。Source code 压缩包不是安装包。

- [详细安装与升级说明](https://github.com/abdvl/olevod-tv-app/blob/v0.2/docs/INSTALL.md)
- [功能与界面截图](https://github.com/abdvl/olevod-tv-app/blob/v0.2/README.md)
- [真机测评记录](https://github.com/abdvl/olevod-tv-app/blob/v0.2/docs/verification/v2/CHROMECAST_V2.md)

**v0.1正式版可以直接覆盖升级**：沿用同一发布证书，无需卸载。通过电视文件管理器打开APK选择更新，或使用已配对的ADB连接：

```sh
adb -s TV_IP:DEBUG_PORT install -r olevod-tv-v0.2.apk
```

开发debug版与发布版签名不同，不能直接覆盖；请先读迁移说明。卸载会删除本机历史和保存凭据，不会删除网站已有的云历史／收藏。

## 新界面与交互

- 合并为单行导航：搜索在首页左侧，默认首页；分类直接进入小首页，目录／历史／收藏／账号工具聚焦展开。
- 首页先显示最近五部，海报上直接显示集数和时间；聚焦展开完整信息，最后一格进入全部历史。精选推荐保留横幅上的大标题。
- 完整竖版海报按比例显示，评分移到海报右上角的深色透明角标，片名使用图下全宽。
- Top 2卡片用本片海报生成模糊背景，配合深色渐变；前景完整海报与文字保持清晰。
- 分类人气榜和评分榜各最多12部：顶部2张推荐卡，下方10部按五列两行排列，不重复前两部。普通分类使用当前年，VIP片库明确显示全部年份，解决当年无VIP影片导致首页空白的问题。
- 目录改用紧凑筛选入口与浮层；保留四种排序、多条件筛选和连续加载。切换条件后显示首行，追加页面及影片返回保留浏览位置。
- 三栏搜索配合遥控键盘与联想；确认建议后进入首个结果，返回先回输入框。
- 八个播放控制、限高简介、十集分组；全屏控制透明覆盖视频，显隐不改变视频尺寸，并显示片源提供的分辨率和码率。
- 两列观看历史、网站历史和收藏；记住账号密码后只需输入验证码，配有数字键盘。
- 修复播放错误登录／重试按钮的遥控焦点；VIP旧会话失效时显示明确登录提示。首页返回需要确认退出。

## 验证与限制

发布APK的构建、签名和覆盖升级结果记录在 [发布验证](https://github.com/abdvl/olevod-tv-app/blob/v0.2/docs/verification/RELEASE_V0_2.md)；本轮三个界面调整另见 [独立复测](https://github.com/abdvl/olevod-tv-app/blob/v0.2/docs/verification/v2/V02_UI_FOLLOWUP.md)。

UI v2开发包已在Google Chromecast with Google TV验证普通／VIP首帧和解码输出、遥控控制、搜索和目录。指定会话修复基线完成30分钟播放采样及实际Home／后台进程恢复；各批次使用的APK分别记载，不把这些结果全部归到发布签名APK上。

现场声音／音画同步、真实4K/HDR、全部无障碍及完整性能指标尚未全面验收。直播按用户要求暂缓。接口、片源、会员权限和设备会影响可用性；云历史依赖网络，尚无持久离线补传队列。

这是个人用途的非官方客户端，不提供或托管影片内容。
