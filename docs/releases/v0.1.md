# 欧乐 TV v0.1

首个可下载安装的 Android TV / Google TV 版本。应用版本0.1.0（versionCode1），最低Android8.0，包名`com.olevod.tv`。

## 安装包

下载 Assets 中的 **olevod-tv-v0.1.apk**；`SHA256SUMS.txt` 用于检查下载完整性。Source code 压缩包不是安装包。

- [详细安装与迁移说明](https://github.com/abdvl/olevod-tv-app/blob/v0.1/docs/INSTALL.md)
- [功能介绍与10张实际界面截图](https://github.com/abdvl/olevod-tv-app/blob/v0.1/README.md)

可以通过电视文件管理器打开APK安装，或使用已配对的ADB连接：

```sh
adb -s TV_IP:DEBUG_PORT install -r olevod-tv-v0.1.apk
```

**此前开发调试版的用户请先阅读迁移说明。** v0.1使用独立发布签名，不能直接覆盖debug版；首次迁移需卸载旧版，会清除本机历史、搜索记录和保存的登录凭据。不会删除网站已有的账号、云历史或收藏。请先核对需要保留的云端记录。

## 功能

- 最近播放首页、推荐及电影/电视剧/综艺/VIP/短剧内容区。
- 分类mini首页：当年人气最高、评分最高各前10部，每组前2部大推荐卡；底部浏览全部进入对应目录。短剧位于导航末尾。
- 多条件目录筛选、人气/评分/更新/上传排序、滚到底部自动加载。
- 三栏搜索、字母数字遥控器键盘、联想词、中文/系统输入法；确认建议后自动选中首个结果，返回聚焦输入框。
- 原生点播及账号允许的VIP内容；播放/暂停、±30秒、±5分钟、速度、收藏。
- 每10集一组选集；全屏透明叠加控制栏不改变视频尺寸，显示片源提供的分辨率/码率信息。
- 电视登录、账号密码本机加密记忆、观看历史、云历史同步及影视收藏。
- 遥控器焦点导航及退出确认，默认继续观看。

## 验证与限制

- Release构建、23项release单元测试、lint与APK签名校验通过；专用签名APK在干净的Android TV API34模拟器首次安装并验证首页/榜单/目录/搜索/播放/历史/退出。
- 同功能开发版已在Google Chromecast with Google TV验证，用户确认普通点播音画正常。未用新签名覆盖/卸载已有电视开发版。
- 直播与回看入口保留，稳定性暂缓；4K/HDR和长时间连续播放未全面验收。
- 网站接口、片源、有效会员权限及设备解码能力会影响功能；云历史同步依赖网络，暂无持久离线补传队列。
- 这是个人用途的非官方客户端，不提供、托管或承诺网站内容可用性。
