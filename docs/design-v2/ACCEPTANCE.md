# UI v2 验收与开发交接

对应 [DESIGN_SPEC.md](DESIGN_SPEC.md)，2026-09-08。下表保留设计定稿时的 **74 条验收要求（66 P0、8 P1）**。实现后的执行证据、覆盖范围及待验收项见 [V2-10](../verification/v2/V2-10.md)；设计文档检查与组件测试均不等同全部用例或 Chromecast 通过。

## 1. 验收方法

- 主要验收设备为用户的 Google Chromecast with Google TV；辅以 Android TV 模拟器、默认与放大字体。
- 测试必须可只用上／下／左／右／确定／返回完成，不能通过鼠标点击跳过焦点问题。
- 固定 mock 数据覆盖长标题、缺海报、未知时长、长集数、无结果、尾页错误和慢响应。网络契约另使用当前 adapter 的单元测试与明确授权的集成环境验证。
- 对照相同路由、状态、视口。比较内容边界、留白、图像比例、文字层级、焦点与按钮顺序；不要求真实影片素材和生成画完全相同。
- 截图使用同一套 fixture 与逻辑密度记录，保留日期、设备、分辨率、density、fontScale、提交 hash、操作步骤。设计图不能当实际运行截图归档。
- 实机无法截取受保护视频时，记录限制，用可捕获测试素材验证几何，另用实机观察确认播放；不把黑屏截图当作成功或失败的唯一证据。
- 视觉参数偏差建议在 ±2 dp 内；文字字形可随系统回退，但比例、完整内容与焦点规则无容差。性能目标要实际测量，不根据观感声称达标。

## 2. 优先级

P0：阻断遥控器主流程、错播／错删／串账号、裁掉焦点或控制、错误 API 参数、违反用户明确要求。全部通过才能交付实现。

P1：信息完整性、非阻断恢复、文案、正常动效及大字体；若未通过必须记录影响与后续动作，不能隐去。

## 4. API 纯逻辑与状态测试

不为常量和简单样式逐条写镜像测试；下面这些会影响实际正确性，需要有断言：

1. 七维筛选路径及四排序映射，切分类清理策略。
2. `CatalogFeed` 成功追加、失败保页、去重、异常重复页、切 query generation。
3. query提交／编辑／分页三个场景仅一次且可取消的自动聚焦意图。
4. episode真实index、十项分组、最后不足十、当前组与正在播放组独立。
5. 跳转边界、未知时长、近片尾续播、分辨率及平均／峰值格式化。
6. 云历史秒／毫秒转换和vodId映射；未知时间不伪造；账号范围冻结。
7. 登录意图期望状态（save=true/false）而非toggle重放；失败保存不显示已记住。

UI 测试验证真实跨区方向移动、弹层焦点限制、完整卡片边界和返回恢复；不只断言组件存在。网络／会员测试若未启用应记“跳过”，不能记通过。现有账号授权、测试配置与验证码规则沿用原项目约定，本次写文档不发起真实账号操作。
