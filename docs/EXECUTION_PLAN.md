# 执行计划与验收清单

基线：[DESIGN.md](DESIGN.md)；接口证据：[API_RESEARCH.md](API_RESEARCH.md)。
当前交付仅为调查和设计；仓库尚无 Android 实现。以下任务均为待执行，不能以浏览器验证替代 Android 验收。

## 1. 阶段依赖与估算

| 阶段 | 工作与产物 | 前置 | 粗估工程日 |
| --- | --- | --- | --- |
| P0 可行性闭环 | 协议补全、登录/播放探针、脱敏契约样例 | 无 | 2–4 |
| P1 TV 基础工程 | 可侧载 TV APK、主题、焦点、网络/数据库框架 | P0 核心播放与登录通过 | 1–2 |
| P2 首页/浏览/搜索 | 元数据、推荐、2×5 分类、分页筛选、中文搜索 | P1 | 2–3 |
| P3 详情/点播 | 剧集、控件、全屏、倍速、继续观看 | P1，接入 P2 | 2–3 |
| P4 直播/回看 | 频道列表、节目单、直播控制、回看 | P3 播放核心 | 2–3 |
| P5 账户/历史/收藏 | 正式登录 UI、会话持久化、完整本地历史、云端能力 | P0 协议结论，P2–P4 | 2–3 |
| P6 实机与交付 | Chromecast 修复、长时测试、签名 APK、安装说明 | P2–P5 | 2–3 |

合计约 13–21 个工程日，仅为单人实现范围估算，不是日历承诺。协议变化、异常片源、赛事独立适配或无法读取云端历史会改变估算。
UI 细节可以使用合成数据推进，但不能因此把 P0 阻塞标记为解决。登录探针在 P0，正式 UI 在 P5，不是到项目末期才研究登录。

## 2. P0：把关键不确定性变成明确结论

### P0.1 元数据和筛选契约

- [ ] 捕获 navs、全局配置、点播类型、直播 conditions，建立 category/type/area/year/initial/membership 映射。
- [ ] 每次只改变一个字段，记录 UI 状态→请求路径→响应结果，确认未知参数位。
- [ ] 对四个排序、跨页、最后一页、空结果、切换分类旧条件进行对照。
- [ ] 确认首页 banners 与推荐用途；每类使用 update 查询获得全局前 10。
- [ ] 核实热搜、中文词、英文词、拼音全拼、缩写四类搜索，确认服务端是否支持。
- [ ] 核实赛事入口是否属于用户要求的导航范围；如有独立协议，列出新增工作量。

产物：`docs/contracts/` 下脱敏 schema、参数对照表、合成 fixture；禁止保存完整用户响应、token 或签名媒体地址。

### P0.2 登录与网络探针

- [ ] 创建最小 Kotlin 网络探针；移植前端时间签名，使用固定时间的合成 golden case 校验，处理系统时间偏移错误。
- [ ] 测试 guest 目录和用户本人登录；验证码由用户输入，验证失败、刷新、过期及重复提交反馈。
- [ ] 验证会话分片、token 失效行为；未发现刷新协议时落实重新登录。
- [ ] 验证 API token 不会出现在 CDN 请求、错误日志或调试输出。
- [ ] 登录成功后重启探针仍能读取会话，退出后不再附带会话。

产物：可重用 API client 和会话实现。登录不能依赖开发电脑 Chrome 导出的固定凭据。

### P0.3 原生播放探针

- [ ] 用 Media3 实际播放至少：普通电影 1、连续剧至少 2 集、VIP 影片 1、直播频道 2、节目回看 1。
- [ ] 验证 URL 获取、重定向、必要请求头、清单和分片请求；不可仅播放复制来的永久样例地址。
- [ ] 检查 seek、暂停恢复、切集、速度、地址过期；记录无凭据的 codec/container/分辨率诊断。
- [ ] 根据真实片源扩充 HEVC/HDR/音轨测试；没有样例的能力标记未覆盖。
- [ ] 在用户 Chromecast 获取 4K/HD 版本、Android 版本和实际 decoder 信息；设备尚不可用时明确阻塞实机结论。
- [ ] 单独测试节目单日期时区和回看权限；不要用 liveHasVod=false 禁用已成功的回看。

通过门槛：至少一个普通点播、VIP、直播、回看可以由客户端独立解析并原生播放；若失败，给出具体链路和响应，再决定是否需要受限 WebView 适配或其他架构。不能未经讨论静默改为整个网站套壳。

### P0.4 云端历史与收藏

- [ ] 检查 `/pub/vod/history/list` 是否仍有效，查明请求体、分页、最大保留范围和排序。
- [ ] 区分 `/pub/user/watches`、`/pub/user/watches/sync`、点播历史各自范围；核对 sync 响应而非只看 200。
- [ ] 将 30s/90s/暂停/重看样例与 record 字段对照，确认 duration、percent 真实单位。
- [ ] 验证账号隔离、跨端较新进度、重复提交与冲突行为。
- [ ] 验证影视/频道收藏列表分页和增删幂等语义；测试后恢复测试前收藏状态。

云端结果分支：完整可读→分页同步；部分可读→明确范围；不可读→本机完整历史。后两者必须写明无法补回网站未开放的数据，并与用户确认是否接受该限制，不能称“已完成全站历史”。

## 3. P1：基础工程与焦点框架

- [ ] Gradle wrapper、稳定依赖锁定、Kotlin、Compose TV、Media3、Room、DataStore、图片加载。
- [ ] TV launcher、banner、横屏、touchscreen not required、网络权限；应用名与图标。
- [ ] 基础页面状态 Loading/Content/Empty/Error、统一重试和弹层。
- [ ] 实现稳定 focus key、返回恢复、面板焦点限制、遥控器与 IME 共存。
- [ ] 两个网络 client 分离；API 错误映射、取消、节流、脱敏。
- [ ] Room migration 基础和账户作用域，不以全局单表混合不同用户。

验收：模拟器仅 D-pad 可走遍骨架；App 能在 TV launcher 出现，无触屏依赖；组装可安装 APK。

## 4. P2：首页、浏览与搜索

- [ ] 推荐区域、动态导航、点播每类 2×5、最近更新、更多入口；分组独立失败。
- [ ] 浏览面板所有已验证筛选、四种服务端排序、分页及焦点锚点。
- [ ] 图片缺失、评分缺失、长标题和 VIP/普通同名项目正确显示。
- [ ] 搜索热词、联想、去抖/取消、分类过滤、本地词历史、字母键盘、系统中文 IME。
- [ ] 未确认拼音匹配时给出诚实输入提示，不能返回本地猜测的“全站结果”。

验收：与网站同条件前一页 ID/次序一致；每类最多 10 条；翻页不丢焦点；快速换条件时旧结果不覆盖新结果；中文遥控器输入可完成搜索。

## 5. P3：详情和点播

- [ ] 详情信息、版本、收藏入口、选集、继续观看及相关内容。
- [ ] 左视频右信息布局，单播放器全屏切换。
- [ ] 播放/暂停、±30 秒、倍速、全屏、收藏；媒体键与 UI 不重复消费。
- [ ] 连续剧切集、自动下一集开关、末集停止、准确 resume。
- [ ] 轨道/字幕只在存在时提供；不强制软件解码未支持蓝光格式。
- [ ] 生命周期、音频焦点、系统 Home/返回、断网重连和授权失效恢复。

验收：暂停状态切全屏仍暂停；切全屏不重载；±30 秒边界不越界；从卡片进入再返回仍定位原卡片；后台不残留声音。

## 6. P4：直播、节目单与回看

- [ ] 频道分类与排序、节目缩略图、直播专用详情。
- [ ] EPG 日期/时区、直播中/未开始/回看显示，回看授权。
- [ ] Live edge、恢复直播、无 DVR 时隐藏 seek 和倍速。
- [ ] 切台取消旧请求，快速换台只保留最后选择；频道无流时可返回选其他频道。
- [ ] 回看与直播历史分离；节目失效显示原因。
- [ ] 如果 P0 确认赛事为独立必需范围，补齐赛事列表、详情、直播/回放 resolver 与相应验收。

验收：两频道切换无旧音频残留；至少一个节目回看可暂停和 seek；无可回看节目的状态正确；当地午夜前后不请求错日节目单。

## 7. P5：登录、历史与收藏整合

- [ ] 正式电视表单、验证码刷新、IME 返回、错误重试和密码脱敏。
- [ ] 加密会话、备份排除、失效后保留回跳意图、退出清理。
- [ ] App 全量本地历史、分组/分页、续播、单条删除/清空确认。
- [ ] 按 P0 结论实现云端同步、来源范围、离线 outbox、账号隔离和冲突策略。
- [ ] 影视/频道收藏页面、失败恢复、列表分页。
- [ ] Guest 记录迁移由用户主动选择；未选择不上传。

验收：重启仍可续播；超过 18 条不被截断；云端不可用时不丢本地进度；切账号不会看到或上传另一账号数据；失败收藏不会显示假成功。

## 8. P6：测试与交付

测试应验证真实风险，不逐行复刻实现。

| 层级 | 关键验证 |
| --- | --- |
| 协议单测 | 固定时钟签名、路径编码、字段单位、业务错误、分页边界、脱敏 |
| Repository 测试 | 过期响应取消、账户隔离、同步冲突、重试与重复写、Room migration |
| Compose 仪器测试 | 网格→详情→返回焦点恢复、弹层焦点、输入法、分页末尾、播放器按键 |
| Media3 探针 | 样本独立解析和播放、seek 边界、切集、生命周期、live/replay 能力 |
| Chromecast 手工测试 | 原装遥控器完整闭环、长时播放、低内存、Home/返回、网络断开恢复 |
| 包检查 | TV launcher/banner、release 安装、版本升级保留历史、无凭据/调试日志 |

建议构建门禁：`./gradlew lint testDebugUnitTest assembleDebug`；有设备后执行 `connectedDebugAndroidTest`。实际 task 名随项目创建确认；当前仓库尚不能执行这些任务。
性能测量按 DESIGN 预算记录实测，首帧时间分解为接口/清单/分片/解码，不能把站点 CDN 延迟误判成焦点性能问题。

最终交付：

1. 可构建源码、锁定依赖与 README。
2. 可侧载 APK、SHA-256 校验、版本说明；个人签名密钥独立保存，不提交仓库。
3. 安装/升级/卸载/清理数据说明，升级沿用签名才能保留数据。
4. Chromecast 设备与固件信息、验收结果、支持的媒体样本清单。
5. 已知限制与 API 更新维护指南；外部接口变化能够定位到 adapter。

## 9. 完成定义

六项原始功能全部有可运行实现及相应验收；直播、VIP、直接登录、最近更新要求都覆盖。
不能把“源码存在接口”写成“端到端成功”，不能把“Chrome 播放成功”写成“Chromecast 验收通过”。
所有无法支持的项必须有具体调查依据和用户认可的替代范围；未解决项保留为未完成，不能用宽泛兼容性说明隐藏。
